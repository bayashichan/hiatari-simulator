# 日当たりシミュレーター

住宅の **軒・屋根・高さ・外壁・窓（サイズ・位置）・庇・樹木・隣家** などを入力し、敷地の緯度経度から
**任意の日付（冬至・夏至・春分・秋分など）の日当たりと日射取得** をシミュレーションする Web アプリです。

## 起動方法

Node.js（v18 以上）が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

配布用ファイルの作成（`dist/` に出力。任意の Web サーバーや GitHub Pages に置けます）:

```bash
npm run build
```

## 主な機能

| 機能 | 内容 |
|---|---|
| 敷地の位置 | 地図（国土地理院の航空写真／標準地図、OSM）をクリック、住所検索（国土地理院API）、Googleマップの座標・URLの貼り付け |
| 建物 | 幅・奥行・階数・基礎高・階高、建物の振れ角（真南からの回転） |
| 屋根・軒 | 切妻（棟方向選択）／寄棟／片流れ／陸屋根、寸勾配、軒の出、ケラバの出、屋根厚 |
| 窓 | 取付け面・階・左端からの位置・幅・高さ・床からの高さ、窓ごとの庇 |
| 樹木 | 常緑樹／落葉樹（落葉期は日射を透過）、樹高・樹冠径・枝下高 |
| 障害物 | 隣家・塀・バルコニーなど（直方体、浮いた物も可、回転可） |
| 日時 | 任意の日付、冬至・夏至・春分・秋分ボタン（その年の正確な日付を計算）、時刻スライダー、再生 |
| 3Dビュー | 影付きの立体表示、太陽の軌跡、「太陽から」視点（見えている面＝日が当たる面） |
| 配置図 | 現在時刻の影、1日の日照時間マップ（等時間日影図に相当、測定面の高さ指定可）、室内床への日だまり、ドラッグで樹木・障害物を移動 |
| 窓ごとの結果 | 日照時間、有効日照時間、直達日射量、日射熱取得量、室内への差込み奥行、時刻別タイムライン |
| 月別比較 | 各月21日の日射熱取得量／有効日照時間（軒・庇の効果の確認に） |
| 太陽位置図 | 選択日・夏至・春秋分・冬至の太陽軌跡 |
| 保存 | ブラウザに自動保存、JSON で保存・読込、結果を CSV 保存、3D 画像保存 |

## Googleマップから緯度経度を取る方法

1. Googleマップで敷地を **右クリック**
2. メニューの一番上に表示される `35.68123, 139.76712` のような数値をクリック（コピーされます）
3. アプリの「Googleマップの座標を貼り付け」欄に貼り付け

Googleマップの URL（`@35.68,139.76` や `!3d35.68!4d139.76` を含むもの）や度分秒表記もそのまま貼り付けられます。
位置を決めたら、地図上のオレンジ枠（建物）と赤線（南面）が航空写真の建物に重なるよう **振れ角** を調整してください。

## 座標と入力の決まり

- 位置の X / Y は **建物の中心が原点**。振れ角 0° のとき X=東(+)・Y=北(+)。振れ角を変えると建物と一緒に回転します（建物軸）。
- 窓の「左端からの距離」は、**外から壁を見たときの左端** からの距離です。
- 窓の高さは **その階の床（FL）から**。1FL は「基礎高」、2FL は 基礎高＋階高 です。
- 振れ角は時計回り（西向きに振れる）が ＋ です。

## 計算方法

- **太陽位置**：NOAA Solar Calculator の算法（大気差補正あり）。日の出・日の入は国立天文台の暦とほぼ一致します（分単位）。
- **日当たり判定**：各窓の面を格子状に分割し、各点から太陽方向へレイを飛ばして、建物本体・屋根・軒・庇・障害物・幹（不透明）と樹冠（透過率あり）との交差を判定します。
- **日射量（晴天時）**：直達日射はブーゲの式、天空日射はベルラーゲの式（大気透過率 P）。
  窓の日射熱取得量 =（直達 × 当たる割合 ＋ 天空 × 0.5 ＋ 地面反射）× 窓面積 × 日射熱取得率 η。
- **有効日照時間**：窓面積のうち日が当たる割合 × 時間 の合計。**日照時間** は窓の一部にでも直射が当たっている時間。

## 制限事項

- 建物は総二階（または平屋）の箱型。L 字型・部分二階・下屋は「障害物」で近似してください。
- 天空日射は軒による遮蔽を考慮していません（直達日射の遮蔽は正確に計算します）。
- 晴天を仮定した値です。実際の天候（曇天率）は考慮していません。
- 地形の起伏・標高は考慮していません。

## ファイル構成

```
src/
  main.js       画面全体の制御
  model.js      入力データ（既定値・保存）
  sun.js        太陽位置・日射量・二至二分の計算
  geometry.js   建物・屋根・窓・樹木の立体形状
  analysis.js   レイキャストによる日当たり解析
  scene3d.js    3D 表示（Three.js）
  planview.js   配置図
  charts.js     太陽位置図・タイムライン・月別グラフ
  sitemap.js    地図（Leaflet）・座標の読み取り・住所検索
  ui.js         入力フォーム
```
